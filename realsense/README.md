# RealSense

This folder contains scripts to interact with the Intel RealSense D435 camera.

- **[get_params.py](get_params.py)**: Retrieves the intrinsic and extrinsic parameters of the camera.

- **[realsense_inference_video.py](realsense_inference_video.py)**: Captures images from the camera, generates predictions, and saves the output as a video.

- **[realsense_inference.py](realsense_inference.py)**: Opens the camera and generates predictions in real-time without saving video.

- **[record_video.py](record_video.py)**: Records video from the camera without running inference.
