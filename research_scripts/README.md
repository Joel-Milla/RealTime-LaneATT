# Research Scripts

- **[dataset_image.py](dataset_image.py)**: Traverses the entire dataset and superimposes lane line annotations on images to visualize the annotated lanes.

- **[heading_error.py](heading_error.py)**: Traverses the entire testing dataset and calculates the heading error (mean angle error) metric.

- **[model_size.py](model_size.py)**: Prints the total number of parameters in the model.

These scripts were used to calculate metrics reported in the paper.
